# PDF CFF page hinting

`--pdf-cff-hinting` enables the bounded CFF hinting profile. The API equivalent is
`cupidimage_pdf_options.cff_hinting = 1`. Combine it with `--pdf-text-aa` for
grayscale fills. The option is off by default and is independent of
`--pdf-tt-hinting`.

It applies to supported embedded CFF programs, CID-keyed CFF and CFF font
substitutes, including the spacing-mark fallback programs. Encrypted Type 1
charstrings and TrueType programs keep their existing paths unless their own
options apply. The profile fits horizontal stem edges through a vertical map;
it does not enable stem darkening or synthetic bold.

## Placement and state

Grid fitting uses a uniform pixel size rounded from the transformed text-space
Y axis. FontMatrix scaling is included in the character-space scale. A checked
16.16 FontMatrix transform and text/device transform then position the fitted
outline. FontMatrix translation is combined with text placement before the
final origin is rounded to 1/64 pixel. It does not change PDF text advances.
Finite singular transforms keep the existing unfitted path.

CID Font DICT matrices are resolved before fitting. An explicit subsidiary
FontMatrix stands alone if the top-level FontMatrix is absent. If both are
explicit, they are concatenated; if the subsidiary matrix is absent, it inherits
the top-level/default matrix. This also fixes unhinted CID rendering that could
previously shrink an FD-only font by an extra factor of 1,000 and produce blank
text. The rule follows the CIDFont matrix handling in the
[PostScript Language Reference, section 5.11.3, pages 374 and 375](https://www.adobe.com/jp/print/postscript/pdfs/PLRM.pdf#page=388).

Composite base and accent programs keep separate hint contexts. Accent offsets
are applied in character space before fitting, including the vertical origin
used by the hint map. Nested composites are rejected. The parent glyph's width
is retained, and PDF Widths, CID W/W2, spacing and writing-mode rules still
control text advancement.

Fitted outlines are owned by the glyph draw call. They are not stored in the
font-space outline cache. The same device outline reaches fills, strokes and
deferred text clipping. Stroke and clip coverage remain binary. Forms inherit
the option, and a Form-local font can be released when its draw is finished.

## Work and failure handling

Type 2 execution now accepts a shared caller budget, with the existing ceiling
of 65,536 tokens per glyph execution. The page adapter admits at most four
million work units for decoding, fitting, component copies and transforms, drawn
from the existing shared page budget. Unused work is returned; work already
spent is not.

The core's coordinate, scale and allocation bounds still apply. Allocation,
invalid hint data, transform overflow or budget exhaustion fails the draw and
releases partial results. Empty outlines, invisible text and zero text-size or
horizontal-scale cases do not execute fitting. Empty masks and unused mask bits
retain diagnosed malformed-input recovery; they are not treated as valid syntax.

## Tests

`make test-pdf-cff-page-hinting` covers:

- PDF width overrides, composite accents and horizontal/vertical CID advances.
- Different private dictionaries, FontMatrix placement and FD-only matrices.
- Rotation, reflection, shear, unequal scales and fractional origins.
- Deferred clipping, cap/join/dash stroke paths and Form-local fonts.
- Spacing-mark fallback equivalence, invalid options and malformed hint fields.
- Sixel output with ordinary, mixed-case and extensionless filenames.

The focused suite has 572 page/API/CLI checks, 969 allocation/cache checks and
350 independent grayscale page matches when the optional reference engine is
available. Stroke and clip cases compare the independently obtained device
outline through the vector paths; they do not claim full independent stroke
raster parity. FontMatrix equivalence cases also run with hinting disabled.

The [standalone core](pdf-postscript-gridfit.md) has separate complete-outline
and glyph-bitmap comparisons. `assets/pdf/native-cff-hinting.pdf` is an owned
visible sample, regenerated by `scripts/generate_pdf_cff_page_hinting_fixture.py`.
Its complete page raster remains decoded-unverified.

## Remaining scope

Flex policy, stem darkening, synthetic bold, fractional
private parameters, broader charstring arithmetic and larger fitting ranges
remain unfinished. Text clipping and strokes still need fractional coverage.
The tested profile is not complete CFF or PDF rendering parity.
